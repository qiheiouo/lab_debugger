# ROS2 小车速度跟踪异常演示数据

这是为 Lab Debugger AI 竞赛版准备的**合成演示数据**，不是实车采集结果。它用于在没有机器人、ROS2 网络或串口硬件时验证 AI 页的操作闭环，提交和答辩时必须如实说明数据来源。

## 场景

小车收到约 `1 m/s` 的直行速度命令。第 5 秒人为增加右轮阻力，里程计速度明显下降，IMU 出现减速度，派生的速度跟踪误差持续超过 `0.4 m/s` 并触发告警；第 8 秒移除阻力后速度恢复。

数据目录是 [session](session)，包含 AI 摘要所需的：

- `metadata.json`：来源与实验标识；
- `values.csv`：控制、里程计、IMU 和派生误差，共 40 个数值样本；
- `events.jsonl`：实验 Marker 与持续误差告警。

它不包含原始 CDR 或真实 Session 原始流，因此只用于“AI 智能诊断（比赛版）”页，不用于证明 ROS2 Agent 或完整 Session 回放能力。ROS2 监听应使用真实 Agent 单独演示。

## 演示步骤

1. 打开“AI 智能诊断（比赛版）”；
2. 选择本目录下的 `session`；
3. 点击“生成本地摘要”，检查 4 个字段和 4 条事件；
4. 实验背景可填写：

   `差速 ROS2 小车执行直行速度阶跃。请判断第 5 至 8 秒速度跟踪异常是否与人为增加车轮阻力一致，并给出复测步骤。`

5. 运行时粘贴 DeepSeek API Key，保持 Flash 模型，确认摘要后发送；
6. 将报告中的字段名、数值范围、Marker 和告警与摘要逐项核对。

## 预期证据，而非预设结论

- `cmd_vel.linear.x` 的峰值为 `1 m/s`；
- `odom.twist.linear.x` 在施加阻力后最低降至 `0.22 m/s`；
- `speed_tracking_error` 峰值为 `0.78 m/s`；
- IMU 在阻力施加和移除附近出现明显纵向加速度变化；
- Marker 明确记录阻力施加/移除时刻，告警记录误差持续越界。

模型应把“与车轮阻力一致”表述为基于实验上下文和相关证据的推断，并建议复测；若模型声称已经检查电机电流、轮速编码器或原始波形，则属于超出所给证据。
