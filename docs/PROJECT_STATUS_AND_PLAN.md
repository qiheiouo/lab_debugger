# 项目进度与后续计划

更新日期：2026-10-18
主线阶段版本：Lab Debugger 0.23

## 当前结论

Lab Debugger 已形成可独立运行的跨平台实验数据调试主链路：多串口/多网络/ROS2 Topic 采集，CSV 与二进制协议解析，实时与历史曲线，派生与滤波，Marker/告警，Session 记录/回放，以及 rosbag2 离线导入。0.23 已恢复长期主线开发，完成固定历史视窗、区间框选和完整精度 CSV 导出。比赛专用 AI 功能继续留在独立分支，不合并回主线。

按“能日常使用”而不是“所有设想都实现”衡量，当前估算如下：

| 维度 | 估算 | 说明 |
|---|---:|---|
| 核心数据链路 | 94% | 采集、解析、实时/历史曲线、导出、记录、回放、ROS2 和时间对齐已闭环 |
| 日常可用版本 | 89% | 主要缺真实设备长稳、少量交互细节和完整教程 |
| 发布产品化 | 79% | 仍需安装包体验、签名、崩溃诊断、升级策略和发布级压力验证 |
| 原长期路线整体 | 86% | TLS、多 Agent、MCAP、超长索引等仍未实现 |

百分比用于排期，不代表质量评分。当前主线功能已有自动测试和多轮 Linux/Humble 报告，但未覆盖所有真实硬件与网络条件。

## 已完成能力

- 最多 16 个本地串口/网络实例动态增删，来源、解析状态、统计和精确发送互相隔离；
- TCP 客户端/服务端、UDP、串口、Remote ROS Agent 并行采集；
- Windows 无需安装 ROS2 即可监听 Linux Agent 提供的 ROS2 Topic，常见消息及可 introspection 的自定义消息可进入曲线，原始 CDR 始终保留；
- CSV 与 JSON 二进制协议、CRC/流重同步、逐来源配置冻结；
- 安全派生表达式、滤波、微分、积分、角度展开；
- Marker、阈值/持续阈值、错误率和无数据告警；
- Session 原始流、数值、结构化帧、事件和配置快照，以及确定性回放；
- rosbag2 SQLite 分卷预检/筛选/导入和真实 CDR 映射；
- 源时间、接收时间、手动偏移、ROS Agent 自动时钟校正及同步质量诊断。
- 固定历史曲线拖动、滚轮缩放、区间框选，以及按勾选字段导出的完整精度 UTF-8 CSV。

## 主线仍待完成

以下内容本轮不继续开发，恢复主线时按优先级处理：

1. 真实 STM32/物理串口、跨机器 TCP/UDP、数小时采集和 921600 baud / 1000 Hz 压力验收；
2. Windows 安装包/便携包发布流程、签名与崩溃诊断；
3. 从安装到 STM32、网络、ROS2、rosbag2、Session 分析的完整图文教程和示例数据；
4. 曲线框选统计、磁盘级历史查询和更高密度数据交互；
5. 超长 Session 后台/稀疏索引，MCAP/压缩存储；
6. Remote Agent TLS/认证、多 Agent 客户端和更多 RMW/网络环境验证；
7. 严格公共时间轴的插值、重采样与跨来源相关性估计；
8. 组合告警、通知、确认/消音及更高级滤波。

## 比赛分支归档边界

`competition/deepseek-analysis-2026` 从 0.22 稳定点分出，包含 DeepSeek 分析和比赛提交材料。用户已决定不再需要比赛功能，因此该分支只作为历史归档保留。`master` 不合并其 API、提示词、演示数据或比赛文档，继续保持离线可用、确定性处理和无云模型依赖。

若未来确实需要智能分析，应重新从当时的主线需求评审，而不是直接合并旧比赛分支。

4. 增加框选区间统计、超长 Session 后台/稀疏索引和磁盘级历史查询；
5. 再评估组合告警、公共时间轴重采样、多 Agent 与 TLS。
