# 项目进度、暂停点与竞赛计划

更新日期：2026-09-14
主线阶段版本：Lab Debugger 0.22

## 当前结论

Lab Debugger 已形成可独立运行的跨平台实验数据调试主链路：多串口/多网络/ROS2 Topic 采集，CSV 与二进制协议解析，实时曲线，派生与滤波，Marker/告警，Session 记录/回放，以及 rosbag2 离线导入。0.22 完成逐来源时间对齐后，主线进入阶段性冻结；竞赛所需 AI 分析不默认合并回长期主线。

按“能日常使用”而不是“所有设想都实现”衡量，当前估算如下：

| 维度 | 估算 | 说明 |
|---|---:|---|
| 核心数据链路 | 92% | 采集、解析、曲线、记录、回放、ROS2 和时间对齐已闭环 |
| 日常可用版本 | 86% | 主要缺真实设备长稳、交互细节和更完整教程 |
| 发布产品化 | 78% | 仍需安装包体验、签名、崩溃诊断、升级策略和发布级压力验证 |
| 原长期路线整体 | 84% | TLS、多 Agent、MCAP、高级曲线/索引等仍未实现 |
| 竞赛提交就绪度 | 55% | 基础软件完整，但竞赛 AI 案例、设计文档定稿、安装包和演示视频尚待完成 |

百分比用于排期，不代表质量评分。当前主线功能已有自动测试和多轮 Linux/Humble 报告，但未覆盖所有真实硬件与网络条件。

## 已完成能力

- 最多 16 个本地串口/网络实例动态增删，来源、解析状态、统计和精确发送互相隔离；
- TCP 客户端/服务端、UDP、串口、Remote ROS Agent 并行采集；
- Windows 无需安装 ROS2 即可监听 Linux Agent 提供的 ROS2 Topic，常见消息及可 introspection 的自定义消息可进入曲线，原始 CDR 始终保留；
- CSV 与 JSON 二进制协议、CRC/流重同步、逐来源配置冻结；
- 安全派生表达式、滤波、微分、积分、角度展开；
- Marker、阈值/持续阈值、错误率和无数据告警；
- Session 原始流、数值、结构化帧、事件和配置快照，以及确定性回放；
- rosbag2 SQLite 分卷预检/筛选/导入和真实 CDR 映射；
- 源时间、接收时间、手动偏移、ROS Agent 自动时钟校正及同步质量诊断。

## 主线暂停后仍待完成

以下内容本轮不继续开发，恢复主线时按优先级处理：

1. 真实 STM32/物理串口、跨机器 TCP/UDP、数小时采集和 921600 baud / 1000 Hz 压力验收；
2. Windows 安装包/便携包发布流程、签名与崩溃诊断；
3. 从安装到 STM32、网络、ROS2、rosbag2、Session 分析的完整图文教程和示例数据；
4. 曲线历史拖动、区间选择、CSV 导出和高密度数据交互；
5. 超长 Session 后台/稀疏索引，MCAP/压缩存储；
6. Remote Agent TLS/认证、多 Agent 客户端和更多 RMW/网络环境验证；
7. 严格公共时间轴的插值、重采样与跨来源相关性估计；
8. 组合告警、通知、确认/消音及更高级滤波。

## 竞赛方向与分支边界

赛事材料给出的主题为“人工智能赋能应用创新”。Lab Debugger 最适合方向一“大模型与智能体应用赛道”：以机器人、嵌入式与实验室调试为垂直场景，展示 AI 如何基于真实 Session 证据辅助定位异常，而不是把通用聊天窗口硬塞进调试器。

计划建立独立分支 `competition/deepseek-analysis-2026`。该分支从稳定 0.22 主线分出，只用于 2026 年竞赛；默认不反向合并 AI 代码，比赛结束可归档或删除，主线继续保持离线、确定和无 API 依赖。

竞赛分支的最小可演示方案：

1. 用户选定一段 Session、曲线、Marker 和告警；程序在本地生成有界的结构化摘要，不默认上传原始 CDR 或整个日志；
2. 用户预览并确认将发送的字段、时间窗和统计量；
3. 调用 DeepSeek 官方 API，返回“异常现象—证据—可能原因—验证步骤—风险提示”的结构化报告；
4. 报告中的每条判断引用本地字段名、时间范围或事件，区分事实、推断和建议；
5. 支持取消、超时、限流、失败重试与离线降级；网络失败不影响原调试功能；
6. API Key 只从环境变量或运行时输入读取，不写入 Git、Session、日志、截图和安装包；
7. 保存提示模板版本、模型名、请求摘要哈希和用户确认记录，便于复现实验与说明 AI 参与范围。

竞赛案例建议使用“ROS2 机器人传感器/执行器异常诊断”：同步采集 IMU、里程计、关节状态和控制量，通过现有派生变量、滤波、时间对齐和告警生成可验证证据，再让模型产出诊断报告。演示时同时展示一个正确建议和一个被证据约束拒绝的过度推断，突出可信性而非单纯生成文本。

## 赛事交付清单

根据用户提供的 2026-09-14 通知截图，作品应在 2026-09-28 前通过赛事网站提交，并准备：

- 可运行完整软件、源代码和 Windows 安装/便携包；

- 原创与第三方依赖清单；
- AI 使用声明：说明哪些内容/代码/素材由何种 AI 工具辅助，哪些是团队原创设计与验证；
- 若使用地图，补充合法来源和有效审图号。

## 恢复工作时的顺序

1. 在竞赛分支完成 DeepSeek 最小适配器、密钥保护和模拟服务测试；
2. 完成 Session 摘要器与结构化诊断报告 UI；
3. 固定一个可公开、无隐私的 ROS2/STM32 示例 Session；
4. 做断网、超时、错误响应、恶意模型文本和超大输入安全测试；
5. 输出竞赛版安装包、设计文档和 3–5 分钟演示视频；
6. 冻结提交并完成现场演示彩排；
7. 比赛结束后归档竞赛分支，主线是否吸收其中的非 AI 通用改进另行评审。
