# 派生变量

Lab Debugger 0.17 可以用已有数值字段生成新的曲线，例如功率、跟踪误差、滤波值或累计量。派生结果会作为普通 `DataSample` 进入实时曲线、统计与 Session `values.csv`，其 `source_id` 为 `derived`。

## 使用方法

1. 先连接数据源，让“实时曲线”页显示实际字段名。
2. 打开“派生变量”页，填写名称、表达式和可选单位。
3. 点击“应用派生变量”。输入依赖都收到有效数值后，新字段会出现在曲线列表。

单一来源的字段可以使用末段简称；只有该简称对应一个完整字段时才会生效：

```text
名称：yaw_error
表达式：target_yaw - yaw
单位：rad
```

当前多源链路会把本地 CSV/二进制字段命名为“`sourceId.字段`”。这类名称包含冒号、斜杠或减号时必须用反引号引用：

```text
名称：power
表达式：`serial:COM5.voltage` * `serial:COM5.current`
单位：W
```

ROS 或 rosbag2 字段同样使用界面实际显示的完整名称，例如：

```text
`/cmd_vel.linear.x` - `/odom.twist.twist.linear.x`
```

## 允许的表达式

- 运算符：`+`、`-`、`*`、`/`、一元正负号和括号；
- 常量：`pi`、`e`；
- 单参数数学函数：`abs(x)`、`sqrt(x)`；
- 双参数数学函数：`min(a,b)`、`max(a,b)`、`pow(a,b)`；
- 三参数函数：`clamp(x, lower, upper)`；
- 滤波函数：`lowpass(x, alpha)`、`highpass(x, alpha)`，其中 `0 < alpha <= 1`；
- 滑动平均：`moving_average(x, count)`，窗口必须是 `1` 到 `4096` 的整数；
- 时域函数：`derivative(x)`、`integral(x)`，时间单位分别为每秒和秒；
- 角度展开：`unwrap_angle(x)`，输入按弧度处理，跨越 `-pi` / `pi` 时保持连续；
- 派生变量可以依赖另一个派生变量，但不允许循环依赖。

例如，对完整来源字段做低通并计算角速度：

```text
filtered_yaw = lowpass(`/imu.yaw`, 0.2)
yaw_rate = derivative(filtered_yaw)
```

低通的第一个输出等于第一个输入；高通的第一个输出为 `0`；移动平均在窗口尚未填满时使用已有样本。微分需要两个时间递增的样本，因此首个样本只用于预热、不产生输出；积分采用梯形积分，第一个输出为 `0`。时间戳不递增时微分重新预热，积分不增加面积。

表达式由内置受限语法树解析，不调用 shell、不加载脚本，也没有文件、网络或进程访问能力。非白名单函数、残缺语法、重复名称、循环依赖和超过资源上限的表达式会被拒绝，原有有效配置继续运行。单个配置最多包含 128 个定义和 512 个有状态函数节点，防止大量滑动窗口无限占用内存。

## 取值与错误语义

引擎保存每个依赖最近一次收到的有限数值；任一相关字段更新时，受影响的派生变量按依赖顺序重新计算。同一 CSV 行、同一二进制帧、同一 Remote Agent SampleBatch 或同一条 rosbag2 消息会先更新全部基础字段，再统一计算一次，避免产生消息内部的中间值或重复推进滤波器。

缺少依赖、除零、负数开方、非法 `clamp` 范围、非法滤波参数、溢出、NaN 或 Inf 均不会生成派生样本；无效上游也会使下游失效，不会继续使用上游的旧值。状态型函数采用事务式更新：只有整条表达式成功，或微分正常进入预热时，内部历史才会推进。这样 `lowpass(x, 0.5) / divisor` 遇到除零时不会暗中改变滤波状态。后续输入恢复有效后会自动继续生成。

如果第二个来源出现相同末段字段名，简称会立即变为歧义并停止输出，不会把两个来源混算。多源场景应始终引用曲线列表中的完整限定名。当前使用“最近有效值”语义；严格的多源同一时刻插值/对齐属于后续同步分析功能。

## Session 与回放

开始 Session 时会清空派生变量的最近值和全部滤波/时域历史，并把当前配置保存到 `configuration/derived_fields.json`。记录期间配置被冻结，避免同一个 Session 中途改变计算含义；尚未声明的迟到数据源也不会参与已冻结 Session 的派生计算。

回放会恢复保存的配置，并从原始记录重新生成派生及滤波曲线。跳转会清空最近值和所有函数历史，从新的位置重新预热，因此同一段输入能确定性得到相同结果。旧 Session 没有派生配置文件时按空配置正常打开。

打开 Session 时只接受 `format_version` 为 `1`、不超过 1 MiB 且最多包含 128 项的派生配置；名称、表达式和单位必须是 JSON 字符串。版本未知、内容损坏、读取不完整或表达式不安全时会明确拒绝打开，并保留当前有效配置，不会执行或静默替换它。
