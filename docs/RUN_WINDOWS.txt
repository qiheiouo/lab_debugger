Lab Debugger Windows 便携版
===========================

直接双击：bin\LabDebugger.exe

首次使用：
1. USB-UART 连接 STM32。
2. 选择 COM 口、波特率和串口参数，点击“添加 / 连接”。如有多个设备，
   更换 COM 口后继续添加；上方列表可分别断开、重连或移除每个实例。
3. 在“终端”页选择 HEX 或 ASCII 查看 RX/TX。
4. 如果 STM32 持续发送 1.24,3.56,23.80 加换行，打开“实时曲线”页，
   设置字段 speed,current,voltage 后点击“应用字段”即可看到曲线。
5. 回放 ROS2 数据时，打开“Session 回放”，可导入单个 .db3 或整个 bag 目录；
   在目录窗口选择需要的 Topic，并查看“原始 CDR + 曲线”或“仅原始 CDR”能力。
   导入成功后会自动打开；常见消息直接进入曲线，所有原始 CDR 都会保留且不会被当成 CSV。
6. 最多 16 个本地串口/网络实例可同时连接，并可和 ROS Agent 一起进入 Session；
   原始字节发送前，在发送区的“发送到”按完整 sourceId 选择具体设备。
   断开的发送目标不会自动改成另一台设备。同名曲线显示为 sourceId.字段名，互不混合。
7. “Marker 与告警”页可以写入人工操作说明，也可以按完整字段名设置高/低阈值和回差；
   Marker 与告警会显示在曲线上并随 Session 回放恢复。
8. 串口和网络使用不同格式时，打开“协议解析”，在“配置目标”中选择具体 sourceId；
   可分别应用 CSV 字段或加载 JSON 二进制协议。“恢复默认”会重新继承默认解析配置。
   开始 Session 后解析配置被冻结，停止记录后才能修改，回放会自动恢复当时的逐来源配置。
9. Session 开始时只冻结当时已打开的来源。记录期间允许这些来源按原配置断开、重连，
   但不能新增、移除或改变来源；停止记录后即可继续管理列表。

程序不要求系统安装 Qt。原始记录使用 .ldraw 格式；源码仓库的
docs/ARCHITECTURE.md 说明了格式、线程模型和后续扩展边界。
