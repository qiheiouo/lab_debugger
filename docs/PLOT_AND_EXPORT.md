# 历史曲线与区间 CSV 导出

Lab Debugger 0.23 在实时曲线页增加固定历史视窗、区间框选和独立 CSV 导出。它只读取当前内存中的 `TimeSeriesStore`，不会修改 Session，也不会暂停串口、网络或 ROS2 的后台采集。

## 浏览历史

1. 用“时间窗口”设置横轴跨度，范围为 1～600 秒；也可以把鼠标放在曲线上滚动滚轮缩放。
2. 保持“框选区间”关闭，在曲线绘图区按住左键水平拖动。程序会进入“历史视图”并自动勾选“暂停曲线”，让视窗固定在绝对时间上；新数据仍继续采集、解析和记录。
3. 点击“回到实时”或取消“暂停曲线”，恢复跟随最新样本。

历史视窗只允许落在当前已保留的数据范围内。每个字段默认最多保留 120000 个内存样本；更早且已被环形缓冲覆盖的数据应从 Session 的 `values.csv` 或原始记录中分析。

## 选择并导出

1. 勾选左侧需要导出的曲线；未勾选字段不会写入文件。
2. 点击“框选区间”，在绘图区按住左键拖出蓝色时间范围。
3. 点击“导出所选 CSV”，选择目标文件。
4. 导出使用临时文件加原子替换；取消、写盘失败或空间不足不会留下一个伪装成成功结果的半文件。

输出采用 UTF-8（带 BOM，便于 Excel 直接识别）和长表格式：

```text
timestamp_ns,relative_seconds,field,value
1730000000000000000,0.000000000,"serial:COM5.speed",1.25
1730000000100000000,0.100000000,"udp:127.0.0.1:9000.speed",1.5
```

- `timestamp_ns`：与曲线、派生变量和告警相同的有效时间轴纳秒值；
- `relative_seconds`：相对所选区间起点的秒数，保留到纳秒精度；
- `field`：完整字段名，包含来源限定；
- `value`：使用足以往返恢复 `double` 的有效数字；
- 各字段采样率可以不同，行按时间排序；同一时刻按字段名稳定排序，不做隐式插值；
- 字段名按 RFC 风格转义，并防止以 `= + - @` 等字符开头时被表格软件当作公式执行。

导出范围两端都包含在结果中。区间内没有样本时仍会生成只有表头的合法 CSV，并在完成提示中显示 0 行。

## 性能与边界

绘图先按可见时间闭区间截取，再使用桶内最小/最大值降采样，因此历史视窗之外的尖峰不会污染当前 Y 范围。CSV 导出开始时会在同一个只读锁内截取全部所选字段，避免采集线程继续写入时让不同字段对应不同截取时刻；重复字段只截取一次，不存在或区间内无数据的字段不会生成伪数据。写盘阶段不再持有时序存储锁，导出不降采样，保留区间内的全部内存样本；各字段使用最小堆按时间归并，并以 64 KiB 左右的批次逐步写盘。当前版本还没有 LTTB、GPU 绘图、磁盘级超长历史查询或框选统计面板；这些属于后续高密度交互工作。
