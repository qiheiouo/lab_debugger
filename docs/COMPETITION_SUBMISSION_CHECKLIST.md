## 建议的视频与现场顺序

视频由参赛者自行录制，建议 4 至 6 分钟：

1. 15 秒说明实验室调试痛点和作品定位；
2. 连接一个真实来源，展示 ROS2 Topic 或串口数据进入实时曲线；
3. 展示时间同步、派生误差、Marker 和告警；
4. 停止 Session 并回放；
5. 进入 AI 页，先展示待发送摘要的数据边界，再调用 DeepSeek；
6. 选一条报告结论返回曲线核验；
7. 说明断网时本地采集和回放不受影响；
8. 最后展示技术架构、测试结果和适用场景。

不要在视频中露出 API Key、个人目录、真实设备隐私信息或赛事账号。合成数据出现时要在画面或讲解中明确说明。

## 冻结标准

满足以下条件后，不再继续增加竞赛功能：

- 最终便携包在两台 Windows 电脑启动通过；
- 一次真实 API 调用和一次断网降级通过；
- 真实案例与合成备用案例均能讲清楚；
- 设计文档、依赖清单、AI 声明和视频完成；
- 最终 Git 提交、远端分支、软件包 SHA-256 与提交材料记录一致。
